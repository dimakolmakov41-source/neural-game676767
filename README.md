## 📖 Описание

Ты начинаешь с одного клика по мозгу и постепенно развиваешь целую нейросетевую империю. Покупай нейросети, собирай звёзды, проходи AI Pass, делай престиж и ставь рекорды.

Игра работает на **телефоне и компьютере**, без установки — просто открой ссылку.
